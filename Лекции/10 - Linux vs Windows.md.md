# Linux vs Windows

## 🎯 Цели на урока

- [ ] Да разберем основните разлики между Linux и Windows

## 📖 Теория

### Основни понятия

В тази лекция ще разгледаме основните разлики между Linux и Windows.  Важно е да знаем разликите, понеже много хора ще ни задават този въпрос по време на техническо интервю.

### Наличие на изходен код

- Linux е с отворен код и това го прави свободен за всеки, който може да го чете, изучава, променя и разпространява. Това ни дава максимално ниво на персонализация.

- Windows е разработен от Microsoft. Неговият изходен код не е разпространен публично. Това означава, че потребителят не може да променя системата напълно, а само ограничено.

### Разходи

- Linux е безплатен
- Windows е платен

### Потребителски интерфейс

- Linux има различни десктоп разновидности като GNOME, KDE и XFCE. Те предоставят различен потребителски интерфейс на потребителите.
- Windows си има стандартен GUI за всички версии

### Command Line Interface

- Конзолата на Linux е самото ядро на Linux 
- Windows - има команден ред и PowerShell

### Инсталиране на софтуер и пакети

- Linux - софтуерът се инсталира с помощта на мениджър на пакети като APT, YUM или Pacman.
- Windows - софтуерът се инсталира с помощта на самостоятелен изпълним файл, като например .exe.
